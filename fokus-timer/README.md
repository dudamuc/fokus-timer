# Fokus-Timer

Ein einfacher Pomodoro-Timer als einzelne HTML-Datei — kein Build, keine Abhängigkeiten.

## Verwenden

`index.html` im Browser öffnen. Das war's schon.

## Funktionen

- Drei Modi: Fokus (25 Min), Pause (5 Min), Lange Pause (15 Min)
- Fortschrittsring mit Countdown-Anzeige
- Zähler für abgeschlossene Fokus-Sessions pro Tag (in `localStorage` gespeichert)
- Aufgabenliste mit Erledigt-Status (ebenfalls in `localStorage` gespeichert)
- Browser-Benachrichtigungen und Signalton bei Ablauf des Timers
- Konfetti-Animation nach abgeschlossener Fokus-Session

## Technik

Reines HTML, CSS und JavaScript — keine Frameworks, keine externen Abhängigkeiten.
